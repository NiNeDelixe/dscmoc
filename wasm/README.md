# WebAssembly для сайта

Активируйте Emscripten SDK (проверено с `4.0.23`), задайте `VCPKG_ROOT` и добавьте
CMake и Ninja в `PATH`. Из корня репозитория:

```sh
cmake --preset wasm-release
cmake --build out/build/wasm-release
node wasm/smoke.mjs
```

Для проверки нужен Node.js 24+. CMake создаёт `static/wasm/tools.js` и
`static/wasm/tools.wasm` и копирует лицензии зависимостей. На GitHub Actions
те же файлы доступны в артефакте `site-wasm`: распакуйте его
в `static/wasm/` при развёртывании Drogon.

## GitHub Pages

На GitHub Pages публикуется автономный генератор шума. Мастер модпаков
по-прежнему требует Drogon для каталога и подготовки экспорта.

В настройках репозитория выберите **Settings → Pages → Source → GitHub Actions**.
Если окружение `github-pages` ограничено веткой `main`, разрешите в нём также
`develop` и теги для публикации дополнительных версий. Первый запуск из `main`
публикует демо в корне сайта, а запуски из `develop` и тегов добавляют свои
версии в `/develop/` и `/<tag>/`.

Для локального предпросмотра запустите `node wasm/build-pages.mjs` после сборки WASM
и откройте `out/wasm-pages/` через локальный HTTP-сервер.

WASM используется для карт шума и записи архивов (ZIP, `.mrpack`, Pakku).
При сборке в браузере моды скачиваются из Modrinth с проверкой SHA-512. Если WASM или загрузка в
браузере недоступны, либо архив превышает 128 МиБ, используется серверный экспорт.
Версии Forge и NeoForge остаются в режиме автоматического выбора, как и раньше.

Модуль статически использует libnoise (LGPL-2.1) и minizip/zlib. Исходники
модуля и команда сборки находятся в [репозитории сайта](https://github.com/NiNeDelixe/dscmoc).
Исходники и патчи зависимостей фиксируются версией vcpkg в `wasm/vcpkg.json`;
при публичном размещении сохраните уведомления и доступ к исходникам для пересборки.
